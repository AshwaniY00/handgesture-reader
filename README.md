# HandGesture Reader

## 📌 Project Overview
HandGesture Reader is a web application that uses computer vision and machine learning to recognize and interpret hand gestures.  
It leverages **Python**, **OpenCV**, and **TensorFlow Lite** models to process input images or live camera feeds and classify gestures in real-time.

## 🚀 Features
- Detects and classifies hand gestures using trained models.
- Supports real-time gesture recognition via webcam.
- Includes dataset preparation and model training scripts.
- Lightweight deployment with Flask server integration.

## 🛠️ Tech Stack
- Python
- OpenCV
- TensorFlow / TensorFlow Lite
- Flask (for web server)
- Java (for Android integration, if applicable)
